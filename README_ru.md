## 🌟 Ключевые особенности

*   **🎯 Глобальное масштабирование разрешения**: Изменение внутреннего разрешения рендеринга для всех 3D VR приложений.
*   **⚡ Управление уровнем мощности GPU**: Ручная установка `max_pwrlevel` и `min_pwrlevel` GPU для фиксации состояний производительности (от пиковой производительности до экономии энергии).
*   **📐 Расширенные настройки рендеринга**:
    *   **Трафаретная сетка (Stencil Mesh)**: Оптимизация ресурсов GPU за счет исключения рендеринга скрытых пикселей.
    *   **Фовеальный рендеринг (FFR)**: Повышение производительности за счет концентрации разрешения в центре обзора.
    *   **FOV текстуры**: Тонкая настройка поля зрения для рендеримых текстур глаз.
*   **🔄 Сброс одним нажатием**: Выделенная кнопка «Восстановить настройки», позволяющая мгновенно вернуть все параметры к безопасным стандартным значениям Pico.
*   **🧩 Автозагрузка настроек**: Интегрированная поддержка модуля LSPosed (Xposed) для автоматического переприменения уровней мощности GPU после каждой перезагрузки.
*   **❓ Интерактивная помощь**: Встроенные кнопки справки для каждого параметра с объяснением технических деталей.
*   **📊 Оптимизированные пресеты**: Выбирайте из предустановленных значений:
    *   **384px**: Ультра производительность
    *   **752px**: Производительность
    *   **1504px**: По умолчанию
    *   **2160px**: Родное разрешение
    *   **2448px**: Специально для Pico
    *   **2816px**: Сглаживание (Anti-aliasing)
*   **🔍 Проверка в реальном времени**: Автоматическая проверка успешности изменений в БД перед перезагрузкой.
*   **🛠️ Современный интерфейс**: Адаптивный дизайн на Jetpack Compose, оптимизированный для горизонтального режима VR (двухколоночный макет).
*   **🌍 Полная локализация**: Поддержка 27 языков с использованием профессиональной терминологии.
*   **🔐 Безопасность Root**: Использует команды `content` для безопасного изменения конфигурации PVR системы.

## ⛏️ Предварительные условия

*   **VR-шлем Pico** (Pico 4, Pico Neo 3 и т. д.)
*   **Root-доступ** (требуется Magisk)
*   **Разрешение суперпользователя**: Предоставьте root-доступ по запросу приложения.

## 📖 Как пользоваться?

1.  **Скачайте и установите** последний `Pico3dResolution.apk`.
2.  **Откройте приложение** и предоставьте права **Root/Superuser** по запросу.
3.  **Выберите целевое разрешение** и/или **уровни мощности GPU** из выпадающих списков.
4.  **Нажмите "Apply"** (Применить).
      *   Если были изменены настройки разрешения/рендеринга, кнопка покажет **"Apply & Reboot"** и шлем перезагрузится.
      *   Если были изменены только **уровни мощности**, кнопка покажет **"Apply"**, и изменения вступят в силу мгновенно без перезагрузки.
5.  **(Опционально) Автоприменение при загрузке:** Чтобы уровни мощности GPU оставались активными после перезагрузки, включите модуль в приложении **LSPosed Manager**.
6.  **Дождитесь завершения процесса**. Ваши новые настройки активны!

## ⁉️ FAQ / Поиск и устранение неисправностей

*   **Почему нужна перезагрузка?**
    *   Служба Pico VR и композитор выделяют свои внутренние буферы рендеринга только при запуске. Перезагрузка необходима, чтобы заставить систему прочитать новые значения `sdk_eyebuffer` из базы данных.
*   **Повлияет ли это на производительность?**
    *   Да. Высокое разрешение (например, 2160px или 2816px) значительно увеличивает нагрузку на GPU. В некоторых играх может наблюдаться падение частоты кадров или повышенный нагрев.
*   **Как проверить изменения?**
    *   Вы можете использовать **PICO Metrics Tool**, чтобы увидеть активные значения "EBW" (Eye Buffer Width) и "EBH" (Eye Buffer Height) в реальном времени внутри шлема.

## 🛠️ Технические подробности

### Как это работает
*   **Разрешение и рендеринг:** Приложение использует root-доступ для изменения базы данных конфигурации PVR (`/data/user_de/0/com.pvr.configuration/databases/config.db`). Оно изменяет параметры `sdk_eyebuffer`, `sdk_enableFFRBySYS`, `sdk_stencilMeshStatus` и `sdk_EyeTextureFov` в таблицах `RuleBean` и `ConfigBean`.
*   **Производительность GPU:** Изменяет узлы sysfs ядра, расположенные по адресам `/sys/class/kgsl/kgsl-3d0/max_pwrlevel` и `min_pwrlevel`, для принудительной установки определенных состояний частоты GPU.
*   **Восстановление при загрузке:** Интегрированный модуль LSPosed перехватывает процесс `system_server` для запуска службы восстановления приложения через запрос `ContentProvider` сразу после завершения загрузки.
